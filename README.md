# 김민주 포트폴리오 분리본

원본 단일 HTML 파일을 아래 구조로 분리했습니다.

```text
minnnjuuu_portfolio_split/
├── index.html
├── css/
│   └── style.css
└── js/
    └── script.js
```

## 실행 방법

`index.html`을 브라우저에서 열면 됩니다.

## 변경 사항

- `<style>` 내부 CSS를 `css/style.css`로 분리
- `<script>` 내부 JavaScript를 `js/script.js`로 분리
- HTML의 inline style 3개를 CSS 클래스로 이동
- 외부 Google Fonts 링크와 GitHub 링크는 그대로 유지
